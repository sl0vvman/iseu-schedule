# ISEU — Android-приложение расписания

Дата: 2026-11-02
Статус: черновик на утверждение

## 1. Задача

Лёгкое быстрое Android-приложение, которое показывает расписание занятий
Международного государственного экологического института им. А. Д. Сахарова
(БГУ) напрямую с сайта `rsp.iseu.by` — без своего сервера, аккаунтов и
уведомлений. Пользователь — студент или преподаватель, который хочет за пару
секунд увидеть пары на текущую или другую неделю.

## 2. Цели

- Расписание **группы**: выбор факультет → форма обучения → курс → группа.
- Расписание **преподавателя**: поиск по списку ФИО.
- Навигация по неделям (текущая, следующая, произвольная), быстрый просмотр
  «сегодня».
- Офлайн-просмотр последнего успешно загруженного расписания.
- Монохромный дизайн, светлая и тёмная темы, без цветовых акцентов.
- Личный APK. Без Google Play, без аналитики и трекинга.
- Минимальный размер и быстрый холодный старт.

## 3. Не-цели

- Уведомления и фоновые оповещения.
- Виджеты, авторизация, редактирование расписания.
- Собственный бэкенд, прокси, хостинг, синхронизация между устройствами.
- Поиск по аудитории (источник его не предоставляет).
- Публикация в магазинах приложений.

## 4. Источник данных

Сайт — legacy ASP.NET WebForms. JSON API нет, авторизации нет, токенов и
подписей нет. Состояние формы передаётся через скрытые поля
`__VIEWSTATE`, `__VIEWSTATEGENERATOR`, `__EVENTVALIDATION` и cookie-сессию.

### 4.1. Расписание группы

`POST/GET http://rsp.iseu.by/Raspisanie/TimeTable/umu.aspx`

1. GET страницы, сохранить все hidden-поля и cookie.
2. Последовательно отправить POST-постбэки с `__EVENTTARGET`:
   `ddlFac` → `ddlDep` → `ddlCourse` → `ddlGroup` → `ddlWeek`.
3. Финальный POST с кнопкой `ShowTT=Показать`.
4. Разобрать `table#TT`.

Значения `value` для факультетов/форм/курсов/групп **меняются каждый
семестр** — их нельзя хардкодить, нужно каждый раз читать из `<select>`.

Колонки таблицы: `Дата | Время | Подгруппа | Дисциплина | Преподаватель |
Аудитория`. Дата содержит день недели и дату; строки с `row-spanned`
задают день для последующих строк; `row-empty` — день без пар;
`row-separator` пропускается.

### 4.2. Расписание преподавателя

`http://rsp.iseu.by/Raspisanie/TimeTable/umuteachers.aspx`

1. GET, сохранить hidden-поля.
2. Постбэки: `DropDownList1` (ID преподавателя, отрицательное число) →
   `ddlWeek`; чекбокс `cbShowDraftForTeacher=on`.
3. Финальный POST `Show=Показать`.
4. Разобрать `table#TT`.

Список преподавателей — 240+ опций в `DropDownList1` (ФИО + должность в
скобках), отдельного поиска на сайте нет — фильтрация на клиенте.

Колонки: `Дата | Время | Контингент | Дисциплина | Тема занятия |
Аудитория`. «Контингент» — группы и курс, например
`ФМОС А61ИТ1, А61ИТ2 (1 курс, 81 чел.)`. Подгруппа приходит маркером в
«Теме занятия»: `[1п/гр]`, `[2п/гр]`.

### 4.3. Сеть и ограничения

- Сайт работает только по **HTTP**; HTTPS-сертификат невалиден для хоста.
  На Android 9+ разрешаем cleartext **только** для `rsp.iseu.by` через
  `network_security_config.xml`.
- Таймаут запроса — 15 с, одна повторная попытка, без бесконечных ретраев.
- Полный цикл на живом сайте занимает ~1 с; последовательные запросы
  выполняются в одной сессии, параллельные загрузки не нужны.
- Кэш каталога (факультеты/группы/преподаватели) — 12 часов; при устаревшем
  сохранённом выборе каталог перезагружается и пользователю предлагается
  выбрать заново.

## 5. Модель данных

```kotlin
enum class Mode { GROUP, TEACHER }

enum class LessonType { LECTURE, PRACTICE, LAB, OTHER }

data class Lesson(
    val dayOfWeek: String,
    val date: LocalDate,
    val timeStart: LocalTime,
    val timeEnd: LocalTime,
    val subgroup: Int?,        // null = общая пара
    val discipline: String,
    val type: LessonType,      // из префикса «лек.» / «практ. зан.» / «лаб.»
    val staff: String?,        // для группы
    val contingent: String?,   // для преподавателя
    val topic: String?,        // для преподавателя
    val audience: String?      // "ауд. ," → null
)

data class WeekSchedule(
    val weekMonday: LocalDate,
    val mode: Mode,
    val targetId: String,
    val targetLabel: String,
    val lessons: List<Lesson>,
    val siteMessage: String?,
    val fetchedAt: Instant
)

data class Catalog(
    val faculties: List<Option>,
    val forms: List<Option>,
    val courses: List<Option>,
    val groups: List<Option>,
    val teachers: List<Option>,
    val weeks: List<Option>,
    val fetchedAt: Instant
)
```

Подгруппы не фильтруются: показываются все пары. Пара с подгруппой получает
текстовый бейдж `1 п/гр` / `2 п/гр` и отличается стилем левой границы
(сплошная — общая пара, пунктирная — подгруппа), чтобы различие не зависело
только от цвета.

## 6. Экраны и дизайн

### 6.1. Первый запуск / смена цели

Один экран с сегментированным переключателем «Группа | Преподаватель».

- Группа: четыре связанных выпадающих списка (факультет, форма, курс,
  группа) + кнопка «Показать расписание».
- Преподаватель: поле поиска и список ФИО с должностями; выбор — тап по
  строке.
- Выбор сохраняется в DataStore; при следующем запуске сразу открывается
  расписание.

### 6.2. Экран расписания

- Верхняя панель: `ISEU`, текущая цель (группа/ФИО), действия — смена цели,
  настройки.
- Неделя: стрелки назад/вперёд, диапазон дат, кнопка «Текущая».
- Контент: `LazyColumn`, сгруппированный по дням. Сегодняшний день выделен
  инвертированной плашкой. День без пар — компактная строка «Нет занятий».
- Карточка пары: время, дисциплина, тип, преподаватель (в режиме группы)
  или контингент (в режиме преподавателя), аудитория, бейдж подгруппы.
- Pull-to-refresh.
- Состояния: загрузка (скелетон), ошибка с кнопкой «Повторить», офлайн —
  баннер «Показано из кэша · обновлено 02.11, 18:20».
- Пустая неделя: «Пар нет» + сообщение сайта, если есть.

### 6.3. Настройки

Тема (системная / светлая / тёмная), смена группы или преподавателя, очистка
кэша, ссылка на источник, версия приложения.

### 6.4. Визуальный язык

- Строгая монохромная палитра, без акцентного цвета.
- Light: фон `#FFFFFF`, поверхность `#F5F5F5`, текст `#0A0A0A`,
  вторичный `#6B6B6B`, границы `#D4D4D4`, выбранное — чёрный фон / белый
  текст.
- Dark: фон `#0A0A0A`, поверхность `#161616`, текст `#F5F5F5`, вторичный
  `#A3A3A3`, границы `#2E2E2E`, выбранное — белый фон / чёрный текст.
- Системный шрифт (Roboto), плотная типографика, без декоративных
  иллюстраций.
- Радиусы 12 dp, разделители 1 dp, без теней и elevation.
- Иконки — только необходимые из Material Icons; R8 вырезает неиспользуемые.

## 7. Архитектура и стек

- Kotlin, Jetpack Compose, Material 3, Navigation Compose.
- MVVM: `ViewModel` + `StateFlow`, репозиторий, ручной DI через
  `Application`-контейнер (без Hilt).
- Сеть: OkHttp + cookie-jar, парсинг HTML через Jsoup.
- Хранение: Room (кэш расписаний и каталога), DataStore Preferences (выбор,
  тема).
- Коррутины/Flow; сеть и парсинг на `Dispatchers.IO`.
- Один модуль `:app`. Пакет `by.iseu.schedule`. Название — `ISEU`.
- `minSdk 24`, `targetSdk`/`compileSdk` — актуальная установленная платформа
  (35 или 36). Android 15 поддерживается.
- Gradle Kotlin DSL + version catalog, R8 для release.
- Политика кэша: сразу показать кэш, обновить в фоне, если старше 30 минут
  или пользователь потянул вниз. Ключ — цель + понедельник недели.
- Фоновой работы и уведомлений нет.

## 8. Обработка ошибок

- Нет сети → кэш, иначе экран ошибки с повтором.
- Таймаут/5xx → одна повторная попытка, затем ошибка; кэш сохраняется.
- Сайт изменил разметку → понятное сообщение «Не удалось разобрать ответ
  сайта», кэш не затирается.
- Сохранённая группа/преподаватель исчезли → перезагрузка каталога,
  предложение выбрать заново.
- Пустая неделя → пустое состояние, а не ошибка.

## 9. Проверка

- JVM-юнит-тесты парсера на сохранённых HTML-фикстурах (группа и
  преподаватель): наследование даты из `row-spanned`, `row-empty`,
  отсутствие атрибута `class`, пустые аудитория/преподаватель, маркеры
  подгрупп, «Контингент» и «Тема занятия».
- Тесты выбора недели: точное совпадение понедельника и запасной вариант
  ближайшей недели.
- Тесты разбора типа пары.
- Живая проверка парсера против сайта отдельным JVM-харнессом (не входит в
  обычный прогон тестов).
- Сборка debug APK; при подключённом устройстве — установка и ручной
  smoke-тест. Сейчас устройство не подключено, поэтому отдаём путь к APK.
- Критерии приёмки:
  - первый запуск позволяет выбрать группу и преподавателя;
  - текущая неделя открывается из кэша мгновенно, холодная загрузка ≤ 5 с;
  - навигация по неделям работает;
  - расписание преподавателя показывает контингент и тему;
  - подгруппы визуально различимы без опоры на цвет;
  - в авиарежиме виден кэш;
  - светлая/тёмная монохромная тема;
  - debug APK собран, путь сообщён.

## 10. Инструменты сборки

Локально нет JDK и Android SDK. Устанавливаются JDK 17 (Temurin) и Android
command-line tools с платформой и build-tools; лицензии принимаются. Сборка
через Gradle wrapper, без Android Studio.

## 11. Решения, оставленные за реализатором

- Переключатель темы в настройках.
